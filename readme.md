# Smart Expense Tracker & Financial Advisor (Desktop Edition)

A professional, modular JavaFX desktop application featuring local data persistence, automated system logging, and an intelligent rule-based financial insights engine.

## Key Features
- **JavaFX Graphical Dashboard:** Built with an interactive TableView, dynamic input forms, and real-time updates.
- **Expense Persistence:** Automatically saves and loads historical transactions locally via structured CSV records.
- **Smart Financial Insights:** Analyzes spending distributions across categories and highlights high-spending ratios.
- **Automated System Logging:** Captures operational activity and runtime events cleanly in logs.
- **CI/CD Integration:** Continuous Integration configured via GitHub Actions.

## Setup & Run
1. Clone repository and open in IntelliJ IDEA as a Maven project.
2. Run Main.java or Launcher.java to launch the desktop UI window.

## Software Engineering Standards
- Architectural separation across UI, core business logic, and logging utilities.
- Managed via Apache Maven with OpenJFX dependencies.
